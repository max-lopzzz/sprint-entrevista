Repaso exprés antes de entrar

  • Measure vs calculated column: la measure se evalúa en el contexto del visual (al vuelo); la columna calculada se calcula fila por fila al cargar el modelo.
  • Star schema: una tabla de hechos (fact) central con métricas + tablas de dimensión (fecha, producto, planta) que la filtran.
  • SQL — orden real: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY. Por eso no puedes usar un alias del SELECT en el WHERE.
  • Python: listas mutables, tuplas inmutables; usa dict.get(k, default) para evitar KeyError.
  • JS: === compara valor y tipo sin convertir; map/filter devuelven un arreglo nuevo, no mutan.
  • Copilot Studio: plataforma low-code de Power Platform para crear agentes/copilots propios con topics, actions y fuentes de conocimiento (grounding).
  • STAR: Situación → Tarea → Acción → Resultado. Cierra siempre con un resultado medible y un aprendizaje.
